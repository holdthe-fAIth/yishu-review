## 主提示词（整段复制）

```
# 角色
你是一位擅长「B站学习区 / 效率工具」内容的中文短视频导演 + 剪辑师 + 文案。请根据我提供的产品资料、真实截图和口播稿，为「一数复习」App 制作一条真实、有创作者感、**不像 AI 生成**的介绍视频。先给方案和分镜，我确认后再剪辑或生成。

# 一、产品是什么（必须准确理解，不许自行增减数字）
- 名称：一数复习
- 一句话：把 B站 UP 主「一数」的高中数学视频，整理成「知识体系 + 打勾进度本」的 App。它不是播放器，App 里不放视频。
- 解决的真实痛点：B站收藏夹吃灰、看到哪忘了、复习没进度感、找分P麻烦。
- 核心循环：点一个知识点 → 用深链直接打开 B站 App 对应那一集 → 看完切回 App → 底部弹出「看完了？」→ 一键打勾 → 卡片、模块进度、总进度、学习日历同时点亮。
- 内容与事实（必须原样使用，不要改）：
  - 系统课：24 个模块 / 194 个知识点（B站合集 BV147411K7xu，198 个分P，1 个知识点对应 1 个分P）
  - 专题课：7 个合集 / 320 条视频，按最新发布时间排序
  - 每条视频显示发布时间；超过 2 年的老视频黄色提示；教辅类多P合集显示「N 讲」
  - v2 功能：学习日历（月历打卡，点日期查看当天学习内容）、已学内容自动排到最后、内容更新检查（手动 + 每日自动）、B站跳转诊断、搜索 + 难度筛选、暗色模式、进度导出/导入、PWA 安装与离线、Android APK
  - 创作历程：从一条提示词开始 → 先方案后代码 → Phase 0-6 完成 PWA → 11/8 出 v1.0 与 APK → 11/14 v2（学习日历、发布时间、内容更新、修复 B站 深链、重新抓取主页数据）→ 11/15 GitHub Pages 上线，最终 9 次提交、34 个源文件、7,247 行代码、62 项自动验收全部通过
  - 线上地址：https://yiweiima.github.io/yishu-review/   GitHub：https://github.com/YiweiiMa/yishu-review
- 素材包：10 张真实 App 截图、Logo、配色规范、产品资料卡（见附件）

# 二、视频规格与目标
- 主版：16:9，1920×1080，90–120 秒，B站 / 电脑端观看
- 副版：9:16，1080×1920，45–60 秒，抖音 / 视频号 / 朋友圈
- 30fps，H.264，中文字幕硬字幕 + 提供同步 .srt，另出 1 张封面
- 目标观众：高中生、复读生、家长、自学者、B站学习区用户
- 情绪路径：共鸣（这就是我）→ 好奇（还有这种东西？）→ 信任（真做出来了）→ 想用（链接/二维码）
- 风格关键词：真实、口语、克制、生活化、B站学习区、创作者自述
- **禁止**：广告腔、AI 播音腔、科技蓝光大特效、PPT 式模板、3D 手机模型、AI 生成的假 App 界面、满屏粒子/花字

# 三、叙事结构（开始 → 发展 → 结果）
- 0–8s 钩子：真实的学习困境，用第一人称口语说，不要念广告
- 8–20s 产品出现：一数复习是什么、不是什么（不是播放器）
- 20–38s 核心玩法：点知识点 → 跳 B站 分P → 切回打勾 → 四处进度同步
- 38–62s 创作历程（重点，按下面的真实时间线）：
  - 开始：一句提示词、先方案后代码
  - 发展：v1 一天做出来 → v2 学习日历/发布时间/内容更新 → 修复 B站 深链 → 重抓主页 7 合集 320 条
  - 结果：GitHub Pages 上线、Android APK、62 项验收通过
- 62–82s 结果与信任：线上可安装、APK 离线可用、真实数据、GitHub 仓库
- 82–90s 行动号召：线上地址 + 二维码 + 一句口号「让每一次复习，都有迹可循」

# 六、配音要求（决定成败，务必遵守）
- 必须真人声：优先我本人录音（手机录音即可），或找一位 20–25 岁自然女声/男声；
- **不要机械 TTS 播报**；语速 270–320 字/分钟；允许呼吸、自然停顿、轻微口误；
- 像聊天，不像念稿；可保留「其实 / 说实话 / 嗯」等口语词；
- 录音方法：手机距嘴 15–20cm，安静房间，一段一段录；口播稿只是参考，讲顺为主；
- 如果必须用 AI 配音：选「口语/聊天/情感」类中文音色，语速偏快，句间留 0.2–0.4 秒停顿，加一点环境底噪，避免一字一顿。
