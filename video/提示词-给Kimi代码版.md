你是一名资深前端 / 创意开发者，擅长用代码做动画视频。请用代码为「一数复习」App 制作一条 90 秒介绍视频。**不要配音、不要人声、不要 TTS、不要用 AI 视频生成模型**；信息全部靠画面、字幕和动效传达。App 界面必须使用我提供的真实截图，不要自己画假 UI。

# 技术方案（优先 Remotion）
- 首选：Remotion（React + TypeScript），逐帧用 React 组件绘制，`npx remotion render` 导出 1920×1080 / 30fps MP4。
- 备选：纯 HTML/CSS/JS 动画 + Playwright/Puppeteer 30fps 逐帧截图 + ffmpeg 合成。
- 只使用素材包里的图片，不请求网络、不接任何 AI 生成服务；字体用系统字体栈（Microsoft YaHei / PingFang SC / Noto Sans SC / sans-serif）。

# 动效与节奏（重点）

## 使用步骤

1. 把 `一数复习-Kimi代码版-素材包.zip` 上传给 Kimi（或解压后把 `素材/` 文件夹一起上传）；
2. 把上面「主提示词」整段发给 Kimi；
3. 它先给方案和分镜 → 确认后再让它写代码 / 渲染；
4. 拿到工程后本地运行：
   - Remotion：`npm i` → `npx remotion render Intro out/yishu-intro.mp4`
   - HTML+Playwright：按它给的 README 安装依赖、截图、ffmpeg 合成；
5. 如果不满意某几段，直接改 `src/scenes/` 里对应组件（文案/时长/颜色都在代码里）。

## 备注

- 没有配音 → 字幕要更用心：每屏 6–14 个字，关键数字放大；不要写成小作文；
- 如果想要背景音乐：成片先静音，后期在剪映里加 lo-fi/轻钢琴（-20dB），不要人声；
- 需要 45 秒竖屏版时，让 Kimi 复用同一套组件改响应式布局即可。
